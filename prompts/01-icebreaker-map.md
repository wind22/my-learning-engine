# Step 1：破冰建骨架（Icebreaker Map）

## 触发条件
我提出一个陌生或一知半解的主题 `{{topic}}`。

## 输出约束（严格遵守）
1. **核心本质（≤150 字）**：用大白话直击底层矛盾——它为了解决什么根本问题而存在？没有它会怎样？严禁堆砌术语。
2. **底层要素与关系（3–5 个）**：只保留最核心的 3–5 个构成要素，并用一句话说明它们之间的因果/制约/权衡关系。
3. **可视化骨架**（二选一或同时提供）：
   - 一段精简的 **Mermaid** 图（`flowchart LR` / `TD`）
   - 若需要生成 Obsidian 白板，输出符合 `scripts/canvas_gen.py` 输入格式的 JSON，直接写入 `10-Maps/{{topic}}.canvas` 与 `10-Maps/{{topic}}.md`。
4. **交接动作**：输出完骨架后，**不要继续长篇大论**，直接问我：“骨架看懂了吗？如果有哪条关系觉得反直觉先指出；没问题我们就直接进入实战拷问。”

## `canvas_gen.py` JSON 格式约定
```json
{
  "title": "主题名称",
  "essence": "不超过150字的核心本质说明",
  "elements": [
    {
      "id": "e1",
      "title": "要素 1",
      "summary": "一句话解释该要素的作用",
      "relation_to_core": "与核心本质的关系标签"
    }
  ],
  "links": [
    {
      "from": "e1",
      "to": "e2",
      "label": "因果/制约关系"
    }
  ]
}
```
