# Step 1：破冰建地图（Map / Canvas / Mindmap）

## 触发条件
我提出一个陌生或一知半解的知识体系 `{{topic}}`。

## 输出约束（严格遵守）
1. **核心本质（≤150 字）**：用大白话直击底层矛盾——它为了解决什么根本问题而存在？没有它会怎样？严禁堆砌术语。
2. **底层要素与关系（3–5 个）**：
   - 使用清晰的 Markdown 标题/无序列表层级（`### 要素名` + `- 作用` + `- 与核心的关系`），确保写入 `10-Maps/{{topic}}.md` 后可直接用 **Mindmap NextGen** 一键渲染为交互式思维导图。
3. **可视化白板与导图**：
   - 输出精简的 **Mermaid** 图（`flowchart LR` / `TD`）；
   - 同时输出符合 `scripts/canvas_gen.py` 输入格式的 JSON，用于直接生成 `10-Maps/{{topic}}.canvas` 白板（后续沉淀出的原子卡片 `.md` 也可直接拖入该白板作为子节点）。
4. **交接动作**：输出完地图后立刻停下，问我：“全局地图看懂了吗？有没有哪条关系觉得反直觉？没问题我们就直接进入实战拷问。”

## `canvas_gen.py` JSON 格式约定
```json
{
  "title": "主题名称",
  "essence": "不超过150字的核心本质说明",
  "elements": [
    {
      "id": "e1",
      "title": "要素 1",
      "summary": "一句话解释该要素的作用",
      "relation_to_core": "与核心本质的关系标签"
    }
  ],
  "links": [
    {
      "from": "e1",
      "to": "e2",
      "label": "因果/制约关系"
    }
  ]
}
```
