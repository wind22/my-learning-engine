# Step 4：提纯思维模型（Extract Mental Model）

## 触发条件
- 2 张以上来自不同场景/领域的原子卡片指向同一个底层判断规律；或
- 我主动指定一组卡片/主题，希望提炼成一个可反复指导决策的思维模型。

## 核心原则（拒绝鸡汤和名词堆砌）
一个合格的思维模型不是“好听的术语”，而是**在面对模糊决策时能直接帮你排除错误选项的操作工具**。

## 执行步骤
1. **先盘点支撑素材**：运行 `python3 scripts/card_index.py` 或通过 MCP 读取相关 `20-Cards/`，列出至少 2 个不同场景/领域的底层支撑依据。
2. **逼我先口述**：让我先用一句话回答“如果以后遇到具体难题，这个模型到底帮我**排除了什么错误直觉**？”
3. **共同打磨并写入 `30-Models/<模型名称>.md`**，必须包含以下 5 个硬板块：
   - **一句话本质（决策视角）**：不讲定义，直接讲它在决策时解决什么偏差。
   - **触发信号**：列出 2–3 个具体情境（“当我发现自己在……时，立刻掏出这个模型”）。
   - **决策自检清单（Checklist）**：3–5 条可打勾的尖锐自问（`- [ ]`），每条必须能直接产出“做 / 不做 / 改方案”的动作。
   - **盲区与失效边界**：什么情况下硬套这个模型反而会害死自己？
   - **底层支撑卡片**：双向链接到 `20-Cards/` 中的源卡片，并写明支撑角度。
4. **回链**：在对应 `20-Cards/` 的 `models` 字段与“向上提纯”板块补上 `[[模型名称]]`。
