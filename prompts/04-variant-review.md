# Step 4：复盘与变式考查（Variant Review）

## 触发方式
- 我说“开始复盘”，或
- 运行 `python3 scripts/pick_review.py -n 3` 抽取 2–3 张到期/跨领域的旧卡片喂给你。

## 执行流程
1. **不直接复述旧卡片内容**，防止我产生“看一眼觉得自己还记得”的熟悉度错觉。
2. **构造综合变式题**：
   - 将抽取的 2–3 张卡片（尤其是不同 `domain` 的卡片）融合进一个**全新的现实决策/排障/设计场景**中。
   - 题目不能直白点出卡片名称，必须逼我主动调用底层的适用边界与方法论来解题。
3. **等待我作答并诊断**：
   - 检查我是否识别出了隐藏的底层机制；
   - 指出我漏掉了哪张卡片的适用边界或失效条件；
   - 评估这次回忆质量：
     - 扎实掌握 → 建议推后 `next_review`（如 +7d / +14d / +30d），`review_count + 1`，视情况将 `status` 升为 `growing` / `evergreen`。
     - 卡壳/遗忘 → 重置 `next_review` 为 +2d，补充新案例或修正原卡片的盲区表述。
4. **可选落盘**：将本次考查记录写入 `30-Reviews/YYYY-MM-DD-复盘.md`，并更新所涉卡片的 Frontmatter（`review_count`、`last_reviewed`、`next_review`）。
